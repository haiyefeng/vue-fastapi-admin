# 更新日志

## v1.0.0（首个功能完整版本）

待办事项小程序首版，8 个功能模块全部由微信云开发（云数据库 + 云函数）实现，无需自建后端。

### 功能清单

| 模块 | 说明 |
|------|------|
| 今日 | 问候语、今日完成度圆环、快捷添加、今日日程、今日待办、今日习惯打卡 |
| 任务 | 收件箱 + 项目/清单导航、按已过期/今天/稍后分组、子任务、时间块、关联项目/计划 |
| 四象限 | 四象限看板、增删改、勾选完成、长按移动象限、截止时间、备注 |
| 日历 | 周视图排程、创建/删除时间块、点开任务详情 |
| 计划 | 进行中/归档计划、进度条、关联任务与习惯、详情 |
| 习惯 | 每天 / 每周固定几天 / 每周 N 次 / 每 N 天四种频率、打卡、连续天数、周进度、暂停/归档 |
| 回顾总结 | 周期（周/月/季/年）数据聚合 + 七步反思法、草稿/完成、历史回顾 |
| 待办统计 | 每日完成柱状图、四象限分布、已完成列表 |

### 技术栈

- 前端：微信小程序原生（WXML / WXSS / JS）
- 后端：微信云开发（6 个云函数：todo / project / goal / habit / review / dashboard）
- 数据：云数据库 8 个集合（todos / projects / categories / subtasks / time_blocks / habits / goals / reviews）

### 设计要点

- 所有日期边界在客户端本地时区计算（纯日期用 `YYYY-MM-DD` 字符串、时间点用毫秒时间戳），避免服务端/设备时区不一致。
- 单用户数据按 `_openid` 隔离，集合权限设为「所有用户不可读写」，读写全部走云函数。
- 习惯采用「惰性生成打卡待办」模式（按频率规则自动生成当天的打卡待办，勾掉即打卡）。

### 与 Web 版的差异（简化项）

- 导航：8 个功能超过 tabBar 上限，tabBar 放「今日/任务/四象限/日历」，其余从今日页快捷入口进入。
- 统计图表为纯 CSS 实现（暂未引入 echarts 的 ec-canvas）。
- 拖拽改象限改为长按弹「移动」菜单。
- 订阅消息真推送未接入（`reminder_time` 字段已存储，属后续可选增强）。
